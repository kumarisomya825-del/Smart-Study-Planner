# Smart Study Planner

A desktop-based study management application developed using **C++ and Qt6** to help students organize their study schedules, manage subjects, track daily progress, and improve productivity.

## Features

- **Subject Management:** Add subjects, topics, and difficulty levels.
- **Automatic Timetable Generator:** Generate study schedules using Round-Robin scheduling logic.
- **Task Tracking:** Track completed and pending study sessions.
- **Analytics Dashboard:** Monitor overall and subject-wise study progress.
- **Daily Progress:** View study activity and progress.
- **Pomodoro Timer:** Focus sessions of 25 minutes followed by 5-minute breaks.
- **Study Streak:** Track consecutive study days and daily goals.
- **Data Persistence:** Save important application data using QSettings.
